# Amazon Reviews Sentiment Analysis

This project performs sentiment analysis on Amazon reviews of unlocked mobile phones.

## Dataset

The dataset was obtained from Kaggle:

https://www.kaggle.com/datasets/PromptCloudHQ/amazon-reviews-unlocked-mobile-phones

The dataset contains Amazon customer reviews of unlocked mobile phones.

## Tasks

- Data loading and preprocessing
- Train/Test Split
- TF-IDF Feature Extraction
- Multinomial Naive Bayes Classification
- Model Evaluation
- Confusion Matrix
